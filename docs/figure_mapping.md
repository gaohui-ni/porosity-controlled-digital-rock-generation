# Figure Registry

This registry maps the current manuscript Figures 1–9 to their code, inputs,
and locally generated outputs. The official full reproduction entry point is:

```bash
python run_pipeline.py --mode full --config configs/main.yaml
```

| Figure | Result | Script or implementation | Required input | Local output |
| --- | --- | --- | --- | --- |
| Fig. 1 | 3D VQ-VAE architecture and reconstruction stage | `scripts/train_256_vqvae_ddpm_lat64_v6_light96_full.py --stage vae`; `src/models/vqvae3d.py` | Main sandstone raw volume and `configs/main.yaml` | `outputs/main_sandstone/vqvae_final.pth` and VQ-VAE training logs |
| Fig. 2 | Conditional latent-space DDPM architecture | `scripts/train_256_vqvae_ddpm_lat64_v6_light96_full.py --stage ddpm`; `src/models/unet3d_film.py` | Raw training volume and trained VQ-VAE | `outputs/main_sandstone/unet_final.pth`, `latent_stats.npz`, and DDPM logs |
| Fig. 3 | Adaptive quantile binarization (AQB) | `scripts/demo_quantile_binarization.py`; `src/sampling/quantile_binarization.py` | Decoded probability volume and target porosity | Binary segmentation, threshold, and achieved-porosity report under `examples/` |
| Fig. 4 | Representative generated volumes and slices at five porosities | `scripts/generate_batch.py` | Released checkpoints and targets 0.11–0.15 | `data/generated_phi_sets/phi*/gen256_*.npz` and `.raw`; manuscript rendering is assembled from these volumes |
| Fig. 5 | Slice-wise porosity along z for real/generated samples | `scripts/plot_slice_porosity.py` | One real binary volume, one generated NPZ/volume, and target porosity | User-selected PNG and adjacent CSV |
| Fig. 6 | Directional two-point probability function and S/V comparison | `scripts/evaluate_s2_lineal_edt.py`; `scripts/evaluate_voxel_and_perm.py` | `data/real256_sets_from_S1_strict/` and `data/generated_phi_sets/` | `results/fig_s2/` and `results/tables/*_voxel_perm.csv` |
| Fig. 7 | Pore/throat geometry, EDT radius, and coordination number | `scripts/evaluate_pore_network_6panel.py`; `scripts/evaluate_coordination_euler.py` | Real and generated binary sample groups | `results/fig_pnm/`, including per-target NPZ/JSON/PNG and topology summaries |
| Fig. 8 | Main-sandstone directional and geometric-mean permeability | `scripts/evaluate_voxel_and_perm.py`; `scripts/compare_metric_tables.py` | Real/generated binary groups, voxel size 3.5 um | `results/tables/real_voxel_perm.csv`, `generated_voxel_perm.csv`, and `permeability_comparison.csv` |
| Fig. 9 | Fontainebleau real/generated permeability validation | `python run_pipeline.py --mode fontainebleau --config configs/main.yaml` | Four external Fontainebleau volumes, released checkpoint, voxel size 5.68 um | `results/fig_fontainebleau/` and `results/tables/fontainebleau_*` |

Figures 1–3 are manuscript schematics assembled from the listed model and
algorithm implementations. Figures 4–9 use numerical or volumetric outputs
generated by the listed scripts. Derived figure-source CSV files are generated
locally and are not distributed in the public repository.

For a lightweight synthetic figure check:

```bash
python scripts/reproduce_figures.py --config configs/main.yaml
```

For detailed commands, see `docs/figure_reproduction.md`.
