# data/fontainebleau

Place the four externally obtained ANU Fontainebleau `uint8` volumes here:

```text
phi0p2045.raw
phi0p1743.raw
phi0p1263.raw
phi0p0853.raw
```

Each volume has shape `480 x 480 x 480` and voxel size `5.68 um`. These
external validation data are not redistributed by this repository.
