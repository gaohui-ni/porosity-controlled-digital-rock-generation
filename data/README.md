# Data

The main-sandstone `800 x 800 x 800` binary micro-CT volume used in this study
is publicly available from Mendeley Data:

https://doi.org/10.17632/vp2yw9c7jj.1

Please place raw binary rock volumes under `data/raw/` if you want to run the full training script locally. The binary convention used in the manuscript is:

- 0 = solid phase
- 1 = pore phase

The external Fontainebleau volumes are third-party ANU data and are not
redistributed by this repository; obtain them from their original provider.
Generated volumes and intermediate results are distributed only where the
repository explicitly lists them.
