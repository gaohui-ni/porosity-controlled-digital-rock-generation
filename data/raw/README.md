# data/raw

Place the released Mendeley Data volume here using its original filename:

```text
Bei_800x800x800.raw
```

The file is a binary `uint8` volume with shape `800 x 800 x 800`, where
`0=solid` and `1=pore`. Raw data are not duplicated in GitHub; final trained
checkpoints are distributed separately under `savedmodels/` through Git LFS.
