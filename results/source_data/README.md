# Manuscript Source Data

The official pipelines write figure source-data tables here:

- `fig8_s2.csv`: directional two-point correlation curves
- `fig9_pnm.csv`: flattened pore-network descriptor curves
- `fig10_permeability.csv`: main-sandstone Real-Gen permeability comparison
- `fontainebleau_compatibility_permeability.csv`: historical Fontainebleau
  compatibility-flow Real-Gen comparison; it is not asserted to be the
  source data for current Fuel Fig. 11

The evaluation pipelines generate these figure source-data tables locally.
These derived CSV files are not distributed in the public repository. They are
available from the corresponding author upon reasonable request.
